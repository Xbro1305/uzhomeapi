# UzHome — фронтенд: UX/UI документация

Описание пользовательского интерфейса витрины и админ-панели: экраны,
компоненты, сценарии, состояния, поведение на мобильных.

Фронт — SSR (Vite SSR + Express + React + react-router + Tailwind), исходники
`~/Code/uzhome-ssr`. Публичные страницы рендерятся на сервере (SEO), затем
«оживают» на клиенте.

---

## 1. Дизайн-система

**Палитра (Tailwind, `brand-*`):**
| Токен | Роль |
|---|---|
| `brand-primary` | приглушённый сине-зелёный — акценты, кнопки, ссылки |
| `brand-dark` | почти чёрный — текст, тёмный сайдбар админки |
| `brand-cream` / `brand-light` | светлый фон, границы |
| `brand-muted` | вторичный серый текст |

**Шрифты:**
- `font-display` — **Cormorant Garamond** (серифный, заголовки, крупные акценты, курсив для выделения).
- `font-body` — **Jost** (гротеск, текст, кнопки, UI); часто с `tracking` (разрядкой) и `uppercase`.

**Стиль:** элегантный, минималистичный, «люксовый текстиль» — много воздуха,
тонкие линии, спокойные тона, аккуратные ховер-эффекты.

**Общие приёмы:**
- Секции появляются с анимацией (`section-fade`, fade + сдвиг вверх) при
  скролле; без JS контент виден сразу.
- Уведомления — тосты (`react-hot-toast`, справа сверху).
- Кнопки: заливка `brand-primary` → `brand-dark` на ховере, либо контурные.

## 2. Публичная витрина (`uzhome.ru`)

Одностраничный лендинг (`HomePage`) со скролл-навигацией по секциям.

### 2.1. Navbar (шапка)
- Фиксирована сверху; прозрачная → белая с тенью при скролле.
- Логотип (клик → наверх), пункты: **Главная · Ткани · Сертификаты · Контакты**
  (плавный скролл к секции).
- **Иконка корзины** со счётчиком добавленных позиций (открывает корзину).
- Мобильный: бургер-меню + иконка корзины.

### 2.2. Hero (первый экран)
- Крупный заголовок «Хлопок природной чистоты», описание, цифры-факты
  (100% хлопок · 50+ расцветок · ЕАС).
- Кнопки: **«Наши ткани»** (скролл к каталогу), **«Связаться»** (к контактам).

### 2.3. Каталог тканей (секция «Наши ткани»)
Для каждой ткани — блок с параметрами (состав, плотность, ширина, **цена**) и
**каруселью расцветок**.

**Карусель:**
- Десктоп до 4 карточек в ряд, планшет 3/2, мобайл 1; свайп/перетаскивание,
  стрелки, точки-пагинация.
- **Карточка расцветки:** фото (лёгкое превью), при наведении — затемнение и
  иконка «увеличить»; снизу подпись (артикул, название).
- **Бейдж наличия** (левый верх): 🟢 «В наличии: N м» или 🔴 «Нет в наличии»
  (по данным 1С).
- Кнопка **«В корзину»** (появляется у позиций в наличии) — добавляет один
  рулон и открывает корзину.
- Клик по карточке → **лайтбокс**: крупное фото (оригинал), зум +/−, стрелки
  влево/вправо, лента миниатюр, счётчик «i / N», закрытие по фону/Esc/крестику.

> **Важно:** на витрине показываются **только расцветки с привязанным кодом
> 1С**. Ткань без единой привязанной расцветки скрыта целиком. Пока коды не
> проставлены — каталог показывает «Ткани скоро появятся».

### 2.4. Сертификаты
Сетка сертификатов/товарных знаков, клик → просмотр в модалке.

### 2.5. Контакты + форма обращения
- Контакты (телефон, email, адрес, часы, карта).
- **Форма:** имя, **телефон с маской `+7 (999) 123-45-67`**, e-mail, сообщение,
  чекбокс согласия. Валидация: имя обязателен, телефон полностью, корректный
  e-mail, согласие. Отправка → заявка уходит в Telegram-группу, тост «Заявка
  отправлена».

### 2.6. Footer
Логотип, навигация, контакты, ссылка на политику конфиденциальности.

## 3. Корзина и оформление заказа (UX)

**Корзина** — выезжающая панель справа (`CartDrawer`), затемнение фона.
Открывается по иконке в шапке или после «В корзину».

**Состояния:**
1. **Пусто** — иконка + «Корзина пуста» + кнопка «К ассортименту».
2. **С товарами:**
   - список позиций (последняя добавленная — **сверху**): миниатюра, ткань,
     расцветка, артикул;
   - **степпер метража**: `−` / `N м` / `+`, шаг = длина рулона, максимум =
     доступно (кнопки блокируются на границах); подпись «X рул. × шаг · доступно N м»;
   - цена позиции; удаление (корзина).
   - Итог: метры и сумма.
   - **Форма заказа:** имя, телефон (маска +7), комментарий.
   - Текст **«Самовывоз с адреса: Иваново, Сосновая 1»**.
   - **Обязательный чекбокс** согласия с политикой — пока не отмечен, кнопка
     «Оформить заказ» заблокирована.
3. **Успех** — галочка, «Заказ принят», номер заказа, напоминание про
   самовывоз, кнопка «Продолжить».

**Обработка ошибок:** если товар разобрали (недостаточно остатка) — тост
«Недостаточно остатка (доступно N м)»; заказ не создаётся.

**Клиентский путь целиком:**
Каталог → видит наличие → «В корзину» → правит метраж → имя+телефон+согласие →
«Оформить» → экран успеха. Заказ мгновенно приходит в Telegram с кнопками
управления.

## 4. Админ-панель (`/admin`)

Клиентское приложение (не индексируется). Вход по логину/паролю.

**Каркас (`AdminLayout`):** тёмный сайдбар слева, разделы:
**Главная · Заказы · Остатки 1С · Ткани · Сертификаты · Контакты · Прочие**,
внизу — «Открыть сайт» и «Выйти».

### 4.1. Заказы
- Карточки заказов, фильтр по статусу (Все/Новый/Подтверждён/Выполнен/Отменён).
- Каждая карточка: номер, статус-бейдж (цветной), дата, имя+телефон (кликабелен),
  комментарий, состав (позиции с метражом/суммой), сумма, адрес самовывоза.
- Кнопки: **Подтвердить** / **Выполнен** (списать остаток) / **Отменить**
  (снять бронь). Синхронизировано с кнопками в Telegram.

### 4.2. Остатки 1С
- Таблица последних данных из 1С: код (с **цветной точкой** привязки), артикул,
  наименование, остаток (правится вручную), бронь, доступно, дата обновления.
- **Поиск** по коду/артикулу/названию.
- **Фильтр со счётчиками:** Все · Привязанные · Не привязанные.
- **Клик по строке** → модалка выбора расцветки (`FabricColorPicker`) для
  привязки этого кода.

### 4.3. Ткани
- Список тканей, разворот → расцветки.
- Форма ткани: название, описание, состав/ширина/плотность, цена/единица/валюта,
  **длина рулона** (шаг продажи), порядок, активность.
- Расцветка: артикул, название, фото, порядок, **код 1С** с индикатором
  (🟢 привязан / 🟠 не задан) и кнопкой **«Выбрать»** → модалка остатков
  (`StockPicker`, поиск, по умолчанию по артикулу расцветки).

### 4.4. Две стороны привязки кода 1С ↔ расцветка
1. **Из ткани:** «Выбрать» у поля кода → таблица остатков → клик по позиции.
2. **Из остатков:** клик по строке → таблица тканей/расцветок → клик по расцветке.
Обе модалки — с поиском; после привязки индикаторы/фильтры обновляются сразу.

## 5. Состояния интерфейса (сводно)

| Состояние | Как показано |
|---|---|
| Загрузка | крутящийся спиннер `brand-primary` |
| Пустая корзина | иконка + «Корзина пуста» + «К ассортименту» |
| Нет тканей/фото | «Ткани скоро появятся» / «Фотографии скоро появятся» |
| Успех действия | зелёный тост / экран успеха с номером заказа |
| Ошибка | красный тост (недостаточно остатка, ошибка отправки и т.п.) |
| Нет наличия | красный бейдж «Нет в наличии», без кнопки «В корзину» |
| Не привязано (админка) | 🟠 точка/бейдж «код 1С не задан» |

## 6. Адаптив (мобильные)

- Шапка: логотип + иконка корзины + бургер; меню разворачивается вертикально.
- Каталог: 1 карточка в ряд, свайп; кнопки крупные под палец.
- Корзина: панель почти на всю ширину экрана.
- Формы: поля в один столбец, крупные тач-цели.
- Фото: лёгкие превью в сетке (важно для мобильного трафика; оригиналы — только
  в лайтбоксе, чтобы не переполнять память).

---

## 7. SEO/SSR — что видит пользователь и краулер

- Публичные страницы приходят с **готовым HTML** (контент виден сразу, до JS) —
  быстрый первый экран и корректная индексация.
- Уникальные `title`/`description` на страницу, превью ссылки (`og:image`) в
  мессенджерах и соцсетях.
- Анимации появления не прячут контент при отключённом JS.
